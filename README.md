1. 概述：

本项目目的是使用深度学习的方法拟合动力学模型预测动作空间轨迹，是基于多层自回归（Multi-layer Autoregressive）和伯努利采样（Bernoulli Sampling）的挖掘机轨迹预测方法。输入数据：历史状态序列（滑动窗口长度100）：大臂/中臂/铲斗角度（位置），大臂/中臂/铲斗角速度（速度），大臂/中臂/铲斗PWM控制信号；输出数据：预测下一时刻的加速度值（3维）。学习过程中，我们使用一条长度为1100的trajectory进行操作。在这一方法当中，使用的多层自回归来得到预测值，再将预测值和真实值进行伯努利随机的混合作为新的100*9维状态输入来进行下一步的预测。

2. 实现：

公司的一个科研方向是通过深度学习算法训练智能体，给定一个动作任务（例如挖掘机机械臂拉水平直线），输入外部环境参数，给出机械臂的三维控制量来完成任务。该训练通过PPO深度学习算法来实现。训练仿真过程当中，我们需要通过历史时刻的大臂/中臂/铲斗角度（位置），大臂/中臂/铲斗角速度（速度），来更新当前时刻的对应物理量。
传统的方法使用真实的物理建模来进行拟合这样一个动力学模型。在本方向上，我们试图使用深度学习的方法来拟合动力学模型预测空间轨迹，期望取得更贴近现实条件的物理学模型。

for e in epochs:
    faker = []
    batch_size = 1100
    fake_n = []
    batches = floor(len(gt) / batch_size)
    
    for b in batches:
        n = 100
        real[0,1099] = gt[(b-1)*1100, (b-1)*1100+1099]
        faker[0,99] = real[0,99]

            for j in [0, n]:
                fake[j][0,99] = real[0,99]
                if j == 0:
                    window = real[i, i+99]
                else:
                    window = real[i, i+99-j]
                    for k in [0, j-1]:
                        window.append(fake[k][i+100-j+k])  # 拼接来自之前不同层数的fake层预测

        fake_n = fake[n][]

            faker[i+100] = model(window)

该方法会生成若干个自回归层数（可以通过调整auto_reg数值调整）。前100项都是和真实数值一致。每次预测当前自回归层的下一状态值时，首先制作模型输入的窗口。对于倒数第n个元素，使用当前回归层的倒数第n层的倒数第n个元素作为输入值，随着倒数个数的增加，所取得自回归层数越浅，直到取到最开始的真实值层。这样我们就能够通过若干次的自回归得到最终的预测层。通过伯努利随机采样，将要取的窗口中的一百个值混杂真实值和预测层值，作为最后的采样输入进网络。通过对每个小的轨迹计算MAE loss来进行梯度回传。

3. 总结讨论：

如果不做任何的自回归或者随机采样，训练结果的MAE值大概在0.08rad和0.08rad/s附近。故采用了这种方法之后，理论的MAE值应该小于此参考值。

我们采用中容量的数据集data/data_med.csv进行训练。经过参数的调节，重要可调参数包括自回归层数auto_reg，伯努利随机采样假值比例bon_p，发现在auto_reg为10层左右，bon_p在0.65左右较为合适，训练的结果能够达到0.02~0.03的MAE loss。

然而此算法由于需要计算每个自回归层数预测值，因此计算量会非常大。同时，该算法在使用更大完整数据集测试反映出了过拟合现象，使用完整数据集训练耗时很长，训练结果也不能达到小数据集上反映出来的精度。
